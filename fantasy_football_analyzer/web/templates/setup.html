Status: {% if ai_available %} API Key Configured {% else %} Not Configured {% endif %}

AI-powered analysis uses Claude to provide intelligent trade evaluations, waiver wire strategy, and live draft recommendations.

How to enable:
  1. Get an API key from console.anthropic.com
  2. Set the ANTHROPIC_API_KEY environment variable before starting the app: 
    export ANTHROPIC_API_KEY="sk-ant-..."
python -m fantasy_football_analyzer web
  3. Or with Docker: 
    docker run -p 5050:5000 -e ANTHROPIC_API_KEY="sk-ant-..." espn-api

AI features appear on Trades, Waivers, and Live Draft pages when the key is set.
